# Clear Bust Website

A modern, responsive website created for **Clear Bust**, a German-inspired beverage brand focused on bold flavours, refreshing visuals, and a premium digital presence.

The website combines clean layouts, product-focused sections, and a strong black, red, and gold visual identity inspired by the brand's German roots.

## Live Website

Add your deployed website link here:

```text
https://clear-bust-demo.netlify.app/
```

## About Clear Bust

Clear Bust is a refreshing beverage brand built around the idea of memorable flavour and premium presentation.

**Brand tagline:**

> A Taste Worth Coming Home To

The website was designed to communicate the brand's identity while giving visitors an easy way to explore products, learn about the company, and contact the brand.

The website showcases Clear Bust's drink collection, including:

## Getting Started

To run the website locally:

### 1. Clone the repository

```bash
git clone https://github.com/NameerHussain999/clear-bust
```

### 2. Open the project folder

```bash
cd clear-bust
```

### 3. Open the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

## Design Direction

The Clear Bust website uses a premium beverage-focused visual style featuring:

* Black, red, and gold brand influences
* Strong typography
* Clean spacing
* Product-focused imagery
* Chilled drink photography
* Ice, condensation, and splash effects
* Modern card layouts
* Minimal yet bold sections

The overall design was created to feel professional while still giving the brand a distinctive personality.

## Brand Message

Clear Bust combines German-inspired branding with a modern beverage experience.

**German roots. Global taste.**

The website aims to make the product feel refreshing, premium, and memorable from the first interaction.

## Responsive Design

The website has been designed to work across different screen sizes, including:

* Desktop computers
* Laptops
* Tablets
* Smartphones

Layouts, navigation, typography, product cards, and sections adapt according to the available screen size.
